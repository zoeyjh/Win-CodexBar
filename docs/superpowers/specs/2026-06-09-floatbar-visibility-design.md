# 플로팅 바 가시성 개선 (이중 링)

작성일: 2026-06-09

## 문제

플로팅 바(FloatBar)는 어두운 반투명 배경(`rgba(20, 24, 28, 0.74)`)에 거의 보이지 않는 테두리(`rgba(255, 255, 255, 0.06)`)를 쓴다. 뒤에 어두운 창이 있으면 바가 배경에 묻혀 눈에 띄지 않는다.

## 목표

어떤 배경(어두운 창·밝은 창) 위에 떠 있든 바의 경계가 또렷하게 분리되어 보이게 한다.

성공 기준: 어두운 창 위에 바를 올렸을 때 바 경계가 한눈에 구분된다.

## 접근: 이중 링 (dual ring)

밝은 내부 테두리와 어두운 외곽 링을 겹친다.

- **밝은 내부 테두리** — 어두운 배경에서 바 경계를 또렷하게 만든다.
- **어두운 외곽 링 + 그림자** — 밝은 배경에서 바 경계를 또렷하게 만들고, 바가 떠 보이게 한다.

둘을 겹치므로 배경의 밝기와 무관하게 항상 한쪽이 대비를 만든다.

## 변경 범위

`apps/desktop-tauri/src/floatbar/floatbar.css`의 `.floatbar` 규칙 **한 곳만** 수정한다.

### 현재

```css
.floatbar {
  border: 1px solid rgba(255, 255, 255, 0.06);
  box-shadow: inset 0 1px 0 rgba(255, 255, 255, 0.05);
  /* ...나머지 속성 유지... */
}
```

### 변경 후

```css
.floatbar {
  border: 1px solid rgba(255, 255, 255, 0.45);          /* 밝은 내부 테두리 */
  box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, 0.05),            /* 기존 상단 하이라이트 유지 */
    0 0 0 2px rgba(0, 0, 0, 0.6),                        /* 어두운 외곽 링 (밝은 배경 대응) */
    0 6px 18px rgba(0, 0, 0, 0.5);                       /* 떠 보이는 그림자 */
  /* ...나머지 속성 유지... */
}
```

색상·그림자 세기 수치는 구현 후 실제 화면을 보며 미세 조정할 수 있다.

## 건드리지 않는 것

- **툴팁(`.floatbar__tooltip`)** — 이미 배경 96% 불투명 + 강한 그림자라 충분히 보인다. 수정하지 않는다.
- **윈도우 크기 / hit rect** — 변경 불필요. 플로팅 바 윈도우(가로 380×220, `window.rs`)가 실제 바보다 충분히 커서 외곽 그림자가 잘리지 않는다. `box-shadow`는 `getBoundingClientRect`를 바꾸지 않으므로 클릭 영역(`setFloatBarHitRect`)도 그대로다.
- **세로(vertical) 모드** — `.floatbar` 규칙은 방향 공통이라 자동 적용된다.
- **Rust / Tauri 코드** — 변경 없음. 순수 CSS 변경이다.

## 검증

1. `.\dev.ps1`로 앱을 실행한다.
2. 어두운 창(예: 코드 에디터, 터미널) 위에 플로팅 바를 올린다.
3. 바 경계가 한눈에 또렷하게 구분되는지 눈으로 확인한다.
4. 밝은 창 위에서도 바가 묻히지 않는지 확인한다.

CSS만 바뀌므로 기존 `FloatBar.test.tsx`(Vitest)에는 영향이 없다.
