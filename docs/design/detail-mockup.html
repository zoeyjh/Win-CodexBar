Why these choices

Down = depleting. Chart axis is % remaining — same number as the bar, the toggle chips, and the reset card. Lines start at 100 % when the cycle resets and trend down; hitting the bottom = empty. A dashed projection extends each line at the current burn rate so "will I hit the limit before reset?" is visible at a glance.

Provider colors only inside the chart and reset card. Three lines need to be distinguishable; everywhere else the green-only status system from the bar still rules. Color hue identifies provider; color saturation/value never encodes status here.

Toggle group is multi-select. All three on by default — the point of this view is comparison. Tapping a chip dims its line + filters the log; doesn't open a separate tab.

Cards have distinct empty states. Chart says "waiting" (data will arrive), sessions says "none yet" (depends on user action), reset says "sign in" (blocked on auth). Each empty state names the next step.
