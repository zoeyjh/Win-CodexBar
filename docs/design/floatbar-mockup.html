Why these choices

One accent, status semantics. All three providers share #8DC63F (SELVAS green) when healthy — the eye scans the bar for any non-green, which always means "look here." Per-provider brand colors would dilute that signal.

32 px height. Tighter than the Win 11 taskbar (48 px) so the bar reads as ambient HUD, not a second taskbar. Three providers fit in ~228 px — a footprint that disappears against a 1440px-wide app.

Acrylic, not opaque. 74 % fill + 24 px backdrop blur matches Win 11 Mica. The bar inherits whatever's behind it, so it never looks "stuck on" a dark IDE or a bright browser.

Reset time off the bar. Per spec — % changes every poll, reset time changes hourly. Constant info on the bar; occasional info on hover. Less to ignore.

Dim, don't hide, on auth-expired. Opacity 0.55 + "— —" keeps the layout stable. A disappearing slot would make the bar feel broken, which is the exact problem we're trying to fix.
